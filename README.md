# Bank Loan Performance Report

A Power BI dashboard backed by SQL queries to analyze a bank's loan portfolio.

## Pages
- Summary: key KPIs (total applications, funded amount, amount received, avg. interest rate, avg. DTI), good vs bad loans
- Overview: trends by month, state, term, purpose, and grade
- Details: loan-level table with filters

## Tech Stack
SQL (queries and KPI calculations), Power BI, DAX

## Repository Contents
- `KPI_Queries.sql`: analysis queries
- `Bank Loan Report.pbix`: Power BI file
